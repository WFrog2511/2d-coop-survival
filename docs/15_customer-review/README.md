# Customer Review

顧客またはプロジェクトオーナーの確認事項は、`type:customer-review` を付けたGitHub Issueを正本にします。このフォルダには回答を複製せず、運用への入口だけを置きます。

1. [顧客レビュー用Issue Form](../../.github/ISSUE_TEMPLATE/customer-review.yml)から、一確認事項につき一つのIssueを作る。
2. Issue番号を確認事項の識別子として、関連Issue・要件・仕様・PRからリンクする。
3. 回答、判断日、影響、反映先をIssueコメントへ記録する。
4. 判断を関連文書や実装へ反映し、反映先をリンクしてからIssueを閉じる。

GitHubを利用できない単独作業時だけ一時記録を作り、オンライン復帰後にGitHub Issueへ移行します。
