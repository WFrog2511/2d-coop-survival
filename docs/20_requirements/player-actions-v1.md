# player-actions-v1 要件

## 成果物段階

Prototype standard のローカル検証用プロトタイプとする。入力・役職選択・弾薬箱取得の状態はブラウザ内だけで扱い、永続化・通信同期は行わない。

## 合意済み要件

- SpaceまたはShiftで同一の回避入力を受け、照準方向へ80px（2 tile）移動する。移動完了まで敵接触ダメージを受けず、壁に当たったときは壁で停止する。回避の再使用待ちは1000msとし、シュッ音を鳴らす。terminalとretryでは進行中の回避を解除する。
- 弾薬箱はプレイヤーの3x3近傍でだけ取得候補になる。接触だけでは取得せず、近接時に`E`の案内を表示し、`E`入力で取得する。既存の弾薬回復量、30秒後の再出現、retry世代管理は維持する。
- ページ表示直後には戦闘を開始せず、ガンナー（青）、スナイパー（紫）、ガンスリンガー（赤）、ブルワーク（オレンジ）、クォーターマスター（緑）のいずれかを選択してから開始する。選択値はデータ、HUD表示、グレースケールのプレイヤースプライトと敵への着弾エフェクトの役職色tintだけに使う。敵スプライトはモノクロームにする。

## 対象外

装甲敵に対するダッシュ固有判定、役職能力・補正・固定装備、救急箱・武器・素材・設置武器の状態モデル、汎用inventory・loot基盤、新規外部asset、永続化、マルチ同期、balance変更は後続Issue #63および#61を含む別sliceで扱う。

## 旧Issue #21の取得方式との関係

Issue #21の「弾薬箱へ接触した時点で即時取得する」挙動は本要件でsupersedeする。`REQ-AMMO-SUPPLY`の弾薬量・再出現契約は維持し、取得入力だけを本要件へ置き換える。
