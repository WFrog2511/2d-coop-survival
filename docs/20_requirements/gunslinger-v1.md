# gunslinger-v1 要件

## 成果物段階

[Issue #68](https://github.com/WFrog2511/2d-coop-survival/issues/68) の Prototype standard ローカル検証用プロトタイプとする。ガンスリンガーの状態はブラウザ内だけで扱い、永続化・通信同期は追加しない。

## 合意済み要件

- 役職IDが `gunslinger` のときだけ、回避中に敵と overlap した場合は既存の接触ダメージを受けず、ブーツナイフでその敵へダメージを与える。同一回避では stable enemy ID ごとに一度だけ処理する。
- ガンスリンガーだけは回避中も既存武器で発砲できる。ほかの役職は回避中に発砲せず、弾薬・リロード状態を変更しない。
- 敵撃破は通常射撃・ブーツナイフを問わず既存の撃破／再出現経路に集約し、ガンスリンガーでは撃破ごとにコンボを1加算する。ブーツナイフで敵を通過できた場合もコンボを1加算し、通常移動速度だけを一時的に強化する。ブーツナイフで撃破した場合は、撃破と通過の両イベントをそれぞれ数える。
- 通常弾、ブーツナイフ、DEVの既存ダメージ経路で敵HPが実際に減ったときだけ、ガンスリンガーのコンボ期限を更新する。最後の有効命中から期限に達したとき、またはプレイヤーHPが実際に減ったときはコンボを0へ戻す。回避中の無敵、DEV無敵、敵接触cooldownで無効になった接触ではコンボを維持する。コンボが0へ戻っても速度buffは既存期限まで維持する。
- ガンスリンガーの回避距離は120px（3 tile）、ほかの役職は80px（2 tile）とする。回避時間160ms、cooldownはガンスリンガー400ms・ほかの役職667ms、無敵は維持し、速度buffは回避速度へは適用しない。
- 初期値および terminal・retry 後は、コンボ、コンボ期限、速度buff期限、同一回避の処理済みIDを初期化する。
- ガンスリンガー選択時は HUD の `data-testid="gunslinger-combo"` でコンボと現在の速度倍率を観測できる。ほかの役職の能力・表示色・固定装備は変更しない。

## 仮調整値

以下は [Issue #68](https://github.com/WFrog2511/2d-coop-survival/issues/68) の調整用定数へ隔離する仮値であり、バランス確認後に後続Issueで見直す。

- ブーツナイフダメージ: 2
- 撃破／通過ごとのコンボ加算: 1
- 通過成功時の通常移動速度倍率: 1.2
- 速度buff継続時間: 3000ms
- コンボ継続時間: 3000ms
- 通常役職の回避距離: 80px
- ガンスリンガーの回避距離: 120px
- 通常役職の回避cooldown: 667ms
- ガンスリンガーの回避cooldown: 400ms

## 対象外

跳弾、集中モード、素材・設備、新敵、マルチ同期、汎用ability framework、役職名・色の全面変更、恒久的なバランス調整は対象外とする。

## 検証

- `tests/player-data.test.ts` で任意deadlineの境界、役職別のdash中発砲可否、コンボと速度buffの状態遷移を確認する。
- `e2e/prototype.spec.ts` でガンスリンガー選択時のcombo panel可視と値更新、命中によるコンボ期限更新、期限到達・実被弾・terminal / retry によるreset、無敵と接触cooldown中のコンボ維持、通常撃破の共通コンボ経路、回避中の一回限りのブーツナイフ、役職別のdash中発砲可否を確認する。
- 距離、速度、cooldown、ダメージ、コンボ加算量、コンボ継続時間、速度倍率、buff継続時間の仮調整値そのものは自動assertせず手動確認する。
- 文書変更後は Markdown link 検査を実行する。
