# prototype-v0 仕様

## 起動とアリーナ

`pnpm dev`でローカルのViteサーバーを起動し、`http://127.0.0.1:5173/`を開く。PCブラウザに800×500pxの固定アリーナを表示する。通信、永続化、複数人状態は持たない。

## 操作と数値

| 項目 | 仕様 |
| --- | --- |
| 移動 | WASDまたは矢印キーで8方向へ毎秒210px。斜め入力は正規化して水平・垂直入力より速くしない。 |
| 照準 | マウス位置へプレイヤーの機体先端を回転させる。 |
| 射撃 | マウス左クリックで毎秒520pxの弾を発射する。弾は敵との最初の衝突直後に無効化され、1発につき敵へ1ダメージだけを与える。画面外の弾は無効化して再利用する。 |
| 敵 | 敵1体がプレイヤーを毎秒115pxで追跡する。敵HPは3、0になると700ms後に初期位置・HP 3で再出現する。 |
| 被弾 | プレイヤーと敵の衝突は1経路だけで判定し、0.9秒ごとに20ダメージを与える。プレイヤーHPは100、敵HPとプレイヤーHPは0未満にしない。 |

## 状態と表示

通常状態では移動、照準、射撃、敵追跡を実行する。プレイヤーHPが0になると敗北状態へ移る。敗北状態では物理演算を停止し、弾を無効化して移動・射撃・敵の追跡と被弾を止める。DOM HUDにプレイヤーHP、敵HP、FPSを表示し、HP変化時に更新する。敗北理由と再挑戦ボタンもDOMに表示する。

再挑戦は、物理演算、プレイヤーHP、敵HP、プレイヤー位置、敵位置、両者の速度、敵のactive/visible状態、敗北表示、接触クールダウン、発射済み弾、敵再出現タイマーを初期状態へ戻す。

## 代表E2E

PlaywrightのChromiumで、ページエラーなしに初期の両HPを確認し、敵との接触で敗北表示が出ること、再挑戦後に敗北表示が隠れ両HPが初期値へ戻ることを確認する。

## 手動確認

Google Chrome最新版で移動、照準、射撃、敵撃破後の再出現、被弾、敗北、再挑戦を一続きで確認する。FPSはChrome上で実測してIssue #3へ記録する。初回計測後に合否閾値をdecisionで決める。
